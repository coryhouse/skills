# Skills

Reusable skills for LLMs.

## Install

```bash
npx skills@latest add coryhouse/skills
```

| Skill | What it does |
| --- | --- |
| [`tune-instructions`](./skills/tune-instructions) | Consolidates scattered AI instruction files into `AGENTS.md`, cuts bloat, verifies remaining claims against the codebase, and surfaces missing context. |

The installer prompts for which skills to install and which agent(s) (Claude Code, Codex, Cursor, etc.) to install them into. See [skills.sh](https://skills.sh) for details.
